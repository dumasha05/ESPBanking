# Contributing to ESPBBanking1

Thank you for your interest in `ESPBBanking`! However, please review the contribution policy below before submitting any code, issues, or pull requests.

## Contribution Status
Because this project is proprietary and source-available (All Rights Reserved), **public code contributions, pull requests, and forks are not accepted.** 

* **No Pull Requests:** We cannot accept external code submissions, patches, or pull requests into the main repository due to licensing and proprietary restrictions.
* **Feature Requests & Feedback:** If you have ideas for new features or improvements, you are welcome to open a GitHub Issue for discussion, but code implementations must be developed internally.

---

## Reporting Issues & Bugs
If you encounter a bug or technical issue:
1. Check existing issues to see if it has already been reported.
2. If it's a standard bug in the Free or Pro versions, you may open a public issue.
3. **Security Vulnerabilities:** Do not report security flaws publicly. Please report them privately via email to ensure responsible disclosure.

---

## Support & Upgrades
* Technical support and troubleshooting are **exclusively reserved for Ultra Pro purchasers**. 
* Free and Pro users utilize the code strictly "as-is" under the project's [Security Policy](SECURITY.md).

By accessing or using this repository, you agree that you have read and understood these terms.
